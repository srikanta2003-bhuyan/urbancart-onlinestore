🛒 UrbanCart – Online Store Homepage

UrbanCart is a responsive online shopping website UI built using HTML, CSS, and JavaScript.
This project demonstrates a modern e-commerce homepage layout with product listings, product details, cart page, and user authentication UI.
It is designed as a frontend web development project to practice UI/UX design and responsive layouts similar to popular e-commerce platforms like Amazon or Flipkart.

🚀 Features
🏠 Homepage with Hero Section
🛍 Featured and Latest Product Listings
📦 Product Details Page
🛒 Shopping Cart Page
👤 Login and Registration Page
⭐ Product Ratings using Font Awesome
📱 Responsive Navigation Menu
🖼 Product Image Gallery
🧾 Cart Price Summary Section
🎨 Modern UI Design

🛠 Technologies Used
HTML5
CSS3
JavaScript
Google Fonts
Font Awesome Icons
